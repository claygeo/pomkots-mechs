Operation Ashen Span is a focused single-level mech-combat experience for Minecraft
Java 1.20.1 Forge. Assault a ruined industrial bridge in a six-build Garage Fleet,
break through an authored 15-unit defense, duel Gatekeeper R-01, use the service stop,
and confront the PMB04 Span Warden.

## What this package is

- One planned handcrafted 10–13 minute single-player mission.
- One fixed 22×14-chunk combat district whose current 680-chunk safety world is blocked
  because it does not contain the genuine 6/6 player-ticket footprint.
- Six distinct player mech builds.
- Authored objectives, gates, reveals, recovery anchors, a modular rival, and a finale.
- A future Modrinth `.mrpack` plus optional matched server overlay after the blocker is
  resolved; neither current artifact is approved for launch.

It is not a standalone executable, campaign, progression system, crafting pack,
procedural wave mode, or public multiplayer server.

## Requirements

- A legitimate copy of Minecraft Java Edition.
- Minecraft 1.20.1, Forge 47.3.3, and Java 17.
- A launcher that can import `.mrpack` files.
- A new isolated profile; do not merge with another modpack.

## Start

These instructions are intentionally suspended. Do not import or open RC5 or any
intermediate RC6 package while the safety-envelope blocker remains.

Import the MRPack, open the included `cold_ruin_sector_01` single-player world, and
select a Garage Fleet build from the chat card. `/mechhelp` displays the controls and
`/arena solo status` repeats the current mission status.
